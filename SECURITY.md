# Security Policy

## Reporting a Vulnerability or Privacy Concern

We take security, data privacy, and user safety seriously. If you discover a security vulnerability, a privacy issue (such as exposed personal information), or any unexpected behavior on this site, please report it responsibly.

### How to Report

Please do not open a public GitHub Issue for security or privacy concerns. Instead, report them directly to the maintainer:

* **Contact:** saumya8b@gmail.com

When reporting, please include:
1. A brief description of the issue.
2. Steps to reproduce the issue (if applicable).
3. The potential impact (e.g., data exposure, layout broken).

### Our Commitment

Once a report is received, the maintainer will:
* Acknowledge the report within 24–48 hours.
* Keep the details confidential while working on a fix.
* Apply a patch or remove the affected content as quickly as possible to protect user data.
